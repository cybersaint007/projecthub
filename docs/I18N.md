# Internationalization (I18N)

## Supported Locales

| Locale  | Language              |
|---------|-----------------------|
| `en`    | English (default)     |
| `zh-TW` | Traditional Chinese   |

## Locale Detection Priority

The middleware resolves locale in this order:

1. **Query parameter** (`?lang=zh-TW`) — sets a 180-day cookie
2. **Cookie** (`locale`) — persisted from prior visit
3. **GeoIP** — IP → country → locale via MaxMind GeoLite2
4. **Accept-Language header** — parsed with q-value weighting
5. **Default** — `en` (configured in `config/locale.php`)

Only whitelisted locales in `config/locale.php` → `supported` are accepted. Invalid values are silently ignored.

## GeoIP Setup

### Database

Place the MaxMind GeoLite2 Country database at:

```
storage/app/geoip/GeoLite2-Country.mmdb
```

Download from [MaxMind](https://dev.maxmind.com/geoip/geolite2-free-geolocation-data).

### Environment Variable

```env
GEOIP_DB_PATH=app/geoip/GeoLite2-Country.mmdb
```

### Country → Locale Mapping

Configured in `config/locale.php` → `country_map`:

| Country | Locale  |
|---------|---------|
| TW      | zh-TW   |
| HK      | zh-TW   |
| MO      | zh-TW   |

All other countries fall through to Accept-Language or default.

### Caching

GeoIP lookups are cached for 24 hours (configurable via `locale.geoip_cache_ttl_seconds`). Cache key format: `geoip:{ip}`.

## Proxy / Cloudflare Support

The middleware resolves client IP in this order:

1. `CF-Connecting-IP` header (Cloudflare)
2. Laravel's `Request::ip()` (respects `TrustProxies` middleware)

Trusted proxies are configured to accept all (`*`) in `bootstrap/app.php`.

## Cookie

- **Name:** `locale`
- **TTL:** 180 days
- **Set when:** query override, GeoIP detection, or Accept-Language detection
- **Not refreshed when:** cookie already matches (avoids unnecessary Set-Cookie headers)

## Debug Headers

Available when `APP_DEBUG=true` or `APP_ENV=local`:

| Header            | Description                          |
|-------------------|--------------------------------------|
| `X-Locale`        | Resolved locale                      |
| `X-Locale-Source` | Source: query, cookie, geoip, accept-language, default |
| `X-Client-IP`     | Resolved client IP                   |
| `X-Client-Country`| GeoIP country code or "unknown"      |

These headers are **never sent in production** (`APP_ENV=production` with `APP_DEBUG=false`).

## Updating the MaxMind Database

The GeoLite2 database is updated weekly by MaxMind. To update:

1. Download the latest `GeoLite2-Country.mmdb` from your MaxMind account
2. Replace `storage/app/geoip/GeoLite2-Country.mmdb`
3. Clear the GeoIP cache: `php artisan cache:clear` (or wait for TTL expiry)

## Adding a New Locale

1. Add the locale code to `config/locale.php` → `supported`
2. Add country mappings to `country_map` if applicable
3. Add Accept-Language mappings to `accept_language_map`
4. Create language files in `lang/{locale}/ui.php`
5. Translate all keys from `lang/en/ui.php`

## Language Files

Translation files are located in:

```
lang/en/ui.php      — English
lang/zh-TW/ui.php   — Traditional Chinese
```

Use in Blade templates:

```blade
{{ __('ui.nav_projects') }}
```
